01

Las 6 Etapas del Pipeline CI/CD en espacioGYM

Flujo automatizado de extremo a extremo desde el commit hasta el despliegue en producción

Fase CI • Aprovisionamiento 01

Checkout y Entorno Node 22

Se dispara en cada push o pull_request a main/develop. Descarga el código con historial completo (fetch-depth: 0), configura Node.js 22 LTS con caché y ejecuta instalación limpia mediante npm ci.

actions/checkout@v4 actions/setup-node@v4 npm ci
Fase CI • Compilación y Calidad 02

Build Angular 19 y Linting

Compila la PWA en producción, resguarda el artefacto angular-dist y ejecuta análisis estático de código con ESLint 8.57 + @angular-eslint sobre componentes TypeScript y plantillas HTML.

Angular 19 AOT ESLint 8.57 actions/upload-artifact@v4
Fase CI • Pruebas Unitarias 03

156 Pruebas Unitarias

El Job unit-tests ejecuta 156 especificaciones con Karma y Jasmine en ChromeHeadless, validando Agendamiento (/f2), Coach IA y Membresías con cobertura LCOV superior al 65%.

Karma + Jasmine ChromeHeadless 156 Specs (0 Fallos)
Fase CI • Pruebas de Integración 04

Pruebas de Integración HTTP

El Job integration-tests verifica de forma hermética con HttpClientTesting los 5 servicios críticos: RutinaService, ApiService, QrService, UsuarioService y CursoService.

HttpClientTesting 5 Servicios REST Contratos JSON
Fase CI • Seguridad DevSecOps 05

Auditoría y TruffleHog

El Job security-audit evalúa vulnerabilidades CVE con npm audit y escanea el historial Git con TruffleHog para prevenir fugas de llaves de Gemini, Mercury, Brevo y Firebase.

npm audit TruffleHog Scanner audit-report.json
Fase CD • Contenedores y Release 06

Docker GHCR y Despliegue

El Job docker-publish construye con Buildx las 2 imágenes Multi-Stage (Nginx Alpine y Express), las publica en GHCR y despliega en GitHub Pages y Render.

docker/build-push-action@v6 actions/deploy-pages@v4 Render PaaS
