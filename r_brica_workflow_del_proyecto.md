# RÚBRICA PARA DESARROLLO DEL WORKFLOW DEL PROYECTO EN ACTIONS DE GITHUB

| Criterio | Ponderación | Muy bien (9-10) | Bien (8-9) | Regular (4-8) | Mal (2-4) | No entrega (0) |
| :--- | :---: | :--- | :--- | :--- | :--- | :--- |
| **Descarga de código fuente desde los pasos del YAML** | 5% | Se establecen los pasos adecuados para descargar el código fuente del repositorio y se ejecutan adecuadamente. | Sin valor | Se establecen los pasos adecuados para descargar el código fuente del repositorio, pero no se ejecutan adecuadamente. | Sin valor | No se descarga el código fuente. |
| **Configuración del entorno y dependencias desde los pasos de YAML** | 5% | Se establecen los pasos adecuados para configurar el entorno y dependencias y se ejecutan adecuadamente. | Sin valor | Se establecen los pasos adecuados para configurar el entorno y dependencias, pero no se ejecutan adecuadamente. | Sin valor | No se configura el entorno y dependencias. |
| **Configuración para ejecución de pruebas unitarias desde los pasos de YAML** | 15% | Se establecen los pasos adecuados para configurar la automatización de pruebas unitarias y se ejecutan adecuadamente. | Sin valor | Se establecen los pasos adecuados para configurar la automatización de pruebas unitarias, pero no se ejecutan adecuadamente. | Sin valor | No se configuran las pruebas unitarias. |
| **Configuración para ejecución de pruebas de integración desde los pasos de YAML** | 20% | Se establecen los pasos adecuados para configurar la automatización de pruebas de integración y se ejecutan adecuadamente. | Sin valor | Se establecen los pasos adecuados para configurar la automatización de pruebas, pero no se ejecutan adecuadamente. | Sin valor | No se configuran las pruebas de integración. |
| **Configuración de Análisis estáticos de código desde los pasos de YAML** | 15% | Se establecen los pasos adecuados para realizar Linting que garantiza la calidad del código y se ejecutan adecuadamente. | Sin valor | Se establecen los pasos adecuados para realizar Linting que garantiza la calidad del código, pero no se ejecutan adecuadamente. | Sin valor | No se configura Linting en el archivo. |
| **Configuración de Análisis de Vulnerabilidades desde los pasos de YAML** | 15% | Se establecen los pasos necesarios para establecer un análisis de vulnerabilidades y se ejecutan adecuadamente. | Sin valor | Se establecen los pasos necesarios para establecer un análisis de vulnerabilidades, pero no se ejecutan adecuadamente. | Sin valor | No se configura el análisis de vulnerabilidades. |
| **Configuración para realizar el empaquetado del proyecto (GitHub Packages NPM, YARN o Contenedores Docker)** | 25% | Se establecen los pasos necesarios para publicar los paquetes del proyecto y se ejecutan adecuadamente. | Sin valor | Se establecen los pasos necesarios para publicar los paquetes del proyecto, pero no se ejecutan adecuadamente. | Sin valor | No se configura la publicación de paquetes de manera automatizada. |

> **NOTA:** En caso de requerirse, se deberá incluir dentro del archivo YAML la compilación del proyecto.
